* EVM
  * == 💡simple stack-based architecture💡/
    * machine's size (== size of stack items) == 256-bit
      * Reason: 🧠 facilitate 
        * Keccak-256 hash scheme

      * == maximum size == 1024
    * memory model
      * == byte array
        * word-addressed
          * == access | array -- via -- words (!= bytes)
      * volatile
      * | INITIALLY,
        * 0
    * independent storage model /
      * word addressable word array
      * non volatile
      * part of the system state
      * | INITIALLY,
        * 0
  * ❌NOT follow the standard von Neumann architecture❌
    * Reason: 🧠
      * | von Neumann architecture,
        * program code stored | generally-accessible memory or storage
      * | EVM,
        * program code stored | virtual ROM /
          * interactable -- ONLY through a -- specialised instruction
  * EXCEPTIONAL execution

      * stack underflows
